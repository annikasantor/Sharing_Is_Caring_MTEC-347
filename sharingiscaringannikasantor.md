# Vocal Warm Up Simulator

## How to run the program
The program itself is very easy to run. Just command return inside of the various chunks of code to play the example or exercise. 

To run the vocal warm up with a group, start by explaining the words or to an exercise. You can also state the the solfege for the exercise. Then play the example (multiple times if people need to hear it again) and then have people sing along with the exercise. 

(Optional): For the last exercise, if you want a challenge you can split up the group into two sections and trigger the code twice to sing it in a round! You will need to trigger the code a second time when the first round sings do, do, re, do. You need to trigger it a little bit before the third do to have the timing line up correctly.

Start from the top and work your way to the bottom of the code to complete a full warm up!

At the top of the program there is also a pitch pipe which will play a c4 if you need a reference for where do is. 


## My Process
I began by playing around with different options of options for what direction I wanted to go with for this project. I at first planned to do something with a GUI. I played around with making a couple of sliders, but then I decided to go a different route with this project. I found what we did in class with streams and event streams really fun and wanted to work with those. I did some research to resolidify how streams and event streams work. I had the idea of creating a vocal warmup with event streams that someone could run to help them warmup. I decided to run with this idea and started with the do do re do exercise. I started by writing out all of the midi notes for the first half of the pattern and writing out the durations for them as well. I then copied the durations and rewrote the pattern from the top to create the second half of the pattern. I then went through and sequenced all of the other warm ups as well. The last thing I did was add a pitch pipe at the top and add little examples of each exercise, which can be played before the full exercise to make sure singers understand the pattern.
